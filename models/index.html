    Модели

    Модели для сайта гонок¶

    Team¶

    Модель Team представляет команду участников гонок.

    • name (CharField): Название команды (максимальная длина 100 символов).
    • description (TextField): Описание команды.

    Методы: - __str__(): Возвращает название команды.

    Racer¶

    Модель Racer представляет гонщика.

    • user (OneToOneField): Связь с пользователем системы User (может быть null или blank).
    • team (ForeignKey): Команда, к которой принадлежит гонщик.
    • experience (PositiveIntegerField): Опыт гонщика (количество гонок или уровень опыта).
    • car_description (CharField): Описание автомобиля (максимальная длина 255 символов).
    • bio (TextField): Краткое описание о гонщике.
    • racer_class (CharField): Класс гонщика (выбор: Beginner, Intermediate, Expert).

    Методы: - __str__(): Возвращает имя пользователя и название команды.

    Race¶

    Модель Race описывает гонку.

    • name (CharField): Название гонки.
    • date (DateField): Дата проведения гонки.
    • location (CharField): Место проведения гонки.
    • participants (ManyToManyField): Участники гонки (связь с моделью Racer).
    • registered_racers (ManyToManyField): Зарегистрированные участники.

    Методы: - __str__(): Возвращает название гонки и дату.

    Registration¶

    Модель Registration представляет регистрацию гонщика на гонку.

    • user (ForeignKey): Пользователь, зарегистрировавшийся на гонку.
    • race (ForeignKey): Гонка, на которую зарегистрировался пользователь.
    • racer (ForeignKey): Гонщик, зарегистрированный на гонку.
    • is_confirmed (BooleanField): Подтверждена ли регистрация администратором.

    Методы: - __str__(): Возвращает имя пользователя и название гонки.

    RaceResult¶

    Модель RaceResult описывает результаты гонки.

    • race (ForeignKey): Гонка, к которой относятся результаты.
    • racer (ForeignKey): Гонщик, участвующий в гонке.
    • time (DurationField): Время, затраченное гонщиком.
    • result (CharField): Результат гонщика (например, "1 место").

    Методы: - __str__(): Возвращает результат гонщика для определенной гонки.

    RaceComment¶

    Модель RaceComment представляет комментарии, оставленные участниками.

    • registration (ForeignKey): Регистрация, связанная с комментарием.
    • comment_text (TextField): Текст комментария.
    • comment_type (CharField): Тип комментария (выбор: Вопрос о сотрудничестве, Вопрос о гонках, Иное).
    • rating (IntegerField): Оценка (от 1 до 10).
    • race_date (DateField): Дата гонки.

    Методы: - __str__(): Возвращает информацию о комментаторе и его оценке.
